Comment activer le suivi ?

1. Crée un compte gratuit sur GoatCounter (gratuit pour un usage non commercial).

2. Choisis un identifiant, par exemple noctra-revue.

3. Dans assets/js/config.js, remplace la valeur vide par ton identifiant, puis enregistre le fichier sur GitHub.

4. Consulte ensuite ton tableau de bord GoatCounter pour connaître les visites, les pages vues et les pages les plus consultées. Les données n'apparaîtront qu'après activation.

Note : ce système utilise un service externe de mesure d'audience respectueux de la vie privée. Vérifie sa configuration et les obligations d'information applicables avant activation.
